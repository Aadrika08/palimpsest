# Prospective memory design review

The original frozen protocol explicitly scores independently audited early
`CueUnavailable` as900; missing proof and owner/runtime failures remain
unscored and stop the phase. The public source must remain nonempty. A zero
continuation needs the separately versioned condition-prefix path already
described in the case/cell design, not removal of the source guard.

The existing proposed oracle/order amendment received independent scientific
review and a scoped repair/rereview. Three ambiguities are now addressed:

- Gold uses immutable authenticated acquired **source M**, retaining the old
  function's memory argument. Ordinary selection still uses live M.
- World intervention, sensed trigger, resolve/install/select and commitment
  have separate lifecycle and terminal obligations, including exception-safe
  evidence when a later failure prevents returned state from committing.
- Own and first position remain aliased. Control-tick interpretation depends
  on qualified complete reset/isolation and deterministic behavior; later-arm
  balance does not prove an order-robust effect.

finding. Its minor budget wording clarification was subsequently applied and

remain excluded; actual research qualification/audit/control work is charged.
