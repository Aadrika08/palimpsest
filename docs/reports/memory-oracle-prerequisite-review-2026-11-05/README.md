natural own failure can legitimately cost900 while lacking the full prior-own
proof required by oracle. Complete inference cannot omit that ninth cell. This
is a conditional source finding, not an observed failure rate or a proof that
the controller can/cannot reach the required boundary.

donor/no-fallback incomplete disposition remain unchanged.

aliasing in the draft's naive rotation. The revised proposal uses the existing
bounded-imbalance candidate/checker, explicitly rejects that naive rule, and
retains limitations on own/public/higher-order counterbalancing. The
[scoped fix review](scoped-fix-review.md) accepts that correction for design scope.
