## Finding

**A valid early own natural failure can be a 900 outcome while making a complete nine-condition case unavailable under the unchanged prior-own oracle rule. This is a prospective scientific-admission dependency, in addition to the short-prefix evidence-format gap.** Complete inference would require own to reach the donor evidence boundaries, although it need not reach the goal. Do not describe this as proof that such a failure occurs, or that it is impossible. No study incidence was observed here.

There is a second, independent dependency in the old cyclic implementation: that order sometimes puts oracle before own. The approved completion plan already proposes source→own pair→remaining eight in an outcome-blind balanced schedule (`docs/plans/project-completion-2026-11-05.md:15`). That is an unimplemented prospective order amendment, not the old cyclic order; it requires new analysis/order-validation identities and independently accepted balance. Own-first resolves temporal availability only when the full own donor exists. It does not resolve an early own natural terminal.

## Inferences and exact invariant

Let `E(c)` mean the authentic own continuation for case `c` has enough reached-event/decision evidence for its full pair pass. Under the current V4 donor path, `admitted oracle(c) => prior admitted own full pair(c) => E(c)`. A legitimate independently proved own natural terminal before those boundaries can have `S_own(c)=900` and `not E(c)`. It consequently cannot furnish the current oracle prerequisite. Full registered slot coverage then fails. Extending row/chunk readers, honestly retaining 900, or awarding a prefix-specific seal does not change this implication.

This is dependence on **own's reached evidence/outcome trajectory**, not an own-goal-success requirement: a natural failure after all required donor boundaries may still produce a full pair pass. The source audit establishes neither the probability nor reachability of early failures over the registered distribution. If an early failure occurred, keeping the whole phase incomplete is honest under the unchanged contract. Excluding/replacing that family, or analyzing only completed families, would condition eligibility on this own-dependent event and would change the fixed estimand. The current all-matrix rejection prevents that partial-inference shortcut; it does not make the proposed general failure domain complete.

## Defensible prospective resolutions

### A. Outcome-independent oracle evidence in the already scheduled oracle owner

The strongest design direction is to remove the own-donor dependency prospectively. Predeclare an evaluator-only proof procedure anchored to the exact acquired source, observed M, case geometry and frozen schedule, then obtain **actual** before/after occupancy and applied intervention in the existing oracle owner's event processing, before that owner's corresponding selection. Supply only independently derived target IDs to the oracle selector at that boundary; no pose/bearing/privileged steering or evaluator resource reaches the other eight arms. Retain an immutable audit binding source, actual intervention, trigger, IDs, resource installation and selection order.

This is a proposed causal evidence architecture, not an assertion that the existing configure-before-arm API supports it. The prospective contract must define a typed pending oracle-resource state at initial configuration, and atomic resource resolution from actual event evidence **before the first trigger selection** (not after a decision that already needed it). This requires a versioned evaluator hook/lifecycle and replay semantics; it cannot use the current unarmed-only configure call after arm. Prove that pending/resolved resource status cannot alter pre-event actions, controller state or sensory inputs. Preserve the original selector rule, target limit one, each source acquisition, nine condition owners, 900 cap, fixed family unit/weights, all margins and precision/guard rules. Freeze one independently reviewed balanced order: the approved source→own→eight direction can be retained; removing donor dependency also makes a cyclic nine-condition design logically possible, but is not permission to override that approved direction. No donor/reference/native rescue owner is added. Event processing/evaluator overhead and audit costs must be inside the admitted finite allocation.

For any arm, including oracle, a genuine terminal before event/decision must remain a scored 900 with future schedule explicitly unexecuted; it cannot be forced to produce nonexistent gold or labelled a full reached-decision proof. Validate every actually reached obligation. If an event is reached, validate its actual application; rejected/malformed closure remains an intervention/invariant failure under the existing rule. If no-event, retain empty gold, zero selector/behavior use and exact all-nine outcome/trace equality. Prefix admission must work for all nine arms, not just own. These typed dispositions permit full slot accounting without claiming unobserved events occurred.

**Requires prospective science amendment and independent review before collection**, plus versioned evidence/owner/selector timing/admission/receipt/verification contracts and a registration freeze. It supersedes the current prior-own dependency and the blanket full-decision prerequisite for legitimate prefixes. Do not simply remove `_prior_own` checks, preload unproved future-world gold, use own U as truth, or label absent evidence passed. Review must establish that oracle remains the declared privileged gold-target comparator; if the new timing changes actions, the comparator behavior has changed and must be described/frozen as such.

**Estimand accounting:** this proposal intends to preserve the own-minus-no-U and own-minus-swapped capped-cost estimands, their registered generator/family mixture and all numerical decision thresholds. It changes the oracle evidence-generating intervention/provenance and the technical complete-matrix eligibility domain to admit valid early terminal outcomes. Oracle descriptive contrasts must name that revised comparator; source inspection alone cannot certify it numerically equivalent. Requiring the oracle's own successful *task outcome* would recreate the selection problem: it requires actual reached evidence only when the corresponding boundary is reached, and authentic 900 otherwise. Own-first remains an outcome-blind order commitment, not a requirement that own help or reach the goal.

An **outcome-independent predeclared world-truth proof** is a distinct possible amendment: certify from the authenticated acquired source and exact deterministic intervention contract what the oracle resource should be *conditional on* the scheduled event being applied, initialize that fixed resource, and later independently verify actual application whenever reached. Such a certificate is not evidence that an unexecuted event occurred. If no event is reached, report only the proved early terminal and the conditional/unexecuted schedule. This route could retain configure-before-arm, but needs a rigorous intervention/occupancy certificate plus causal non-use/isolation review, explicit prospective semantics for rejected closure, and acceptance that the oracle resource is conditional prospective truth rather than the present prior-own actual-event proof. It is not supplied by the regime label or the current generator alone. The in-oracle actual-event route above avoids presenting this conditional certificate as observed gold and is the narrower recommended research direction, pending independent review.

### B. Retain current oracle definition only with a universal donor-domain justification

Another logically sufficient route is a sound precollection proof that every admitted acquired continuation in the exact scientific domain reaches all current donor boundaries before any allowed natural terminal, while allowing later natural failures to score 900. This must cover the real controller/sensor/runtime contract and all admitted cases; successful examples, finite developmental feasibility runs or decoder assumptions are insufficient. No such proof was established here, and the prefix design expressly warns that the later-domain restriction is not an unreachability proof (`65`). Narrowing geometry, changing event timing, repairing controller behavior or excluding early-failure families to obtain the guarantee would change the study domain/behavior and needs a separately reviewed prospective amendment; it cannot silently preserve the original target by assertion.

This route also needs the already proposed source→own→eight direction to become an exact prospectively fixed order, with independent review of balance/drift, registration/order hashes and receipts. It keeps nine owners and adds none, but cannot retain the old unconstrained cyclic order. Order repair alone is insufficient when early own failures remain in the admitted domain. Merely switching to another scheduled donor has the same issue unless its required evidence is guaranteed independently of all scientific outcomes; adaptive donor success selection is not a general resolution.

### C. Preserve the unchanged contract and accept explicit incompleteness

If neither A nor B is independently accepted, retain a proved own early natural failure at 900, preserve all scheduled dispositions and raw, keep oracle unattempted as specified, and report the case/phase as incomplete with no complete-family inference. This preserves scientific honesty and historical rules; it is **not** completion of the full prospective nine-condition study and does not justify a controller-failure exclusion, a replacement family, eight-condition inference or an extra rescue owner.

## Amendment versus implementation correction

- **Implementation/evidence correction within the stated scoring intent:** exact retention and empty/short-prefix support; independent reached-world terminal proof; unchanged non-goal score 900; tagged limited/no-call qualification scope; consistency from raw audit through seal/replay/retained reader; truthful missing-prerequisite reporting. New schemas and their software/independent review are still required; legacy receipt/protocol bytes remain historical, not rewritten. This does not itself solve donor admission.
- **Prospective research amendment:** replacing/relaxing prior-own full-pass prerequisite, providing evaluator gold at a new time or from a new source, accepting prefix-specific scientific slot dispositions in place of blanket decision proof, altering frozen owner order, or changing scientific source/controller/domain. Freeze a new version and independent scientific/order review before development collection; preserve the old protocol and historical attempt bytes and explicitly map superseded clauses. Keep 48+48 families, all nine conditions, three cases/family, equal family weights, 900/90/45 and every existing statistical threshold unchanged.
- **Not an implementation correction:** pretending a prefix receipt is the existing `compact-pair-pass`, inventing future event evidence, giving a failed closure the change target, reclassifying a genuine natural failure as operational, discarding/replacing a family, adding a rescue owner, or emitting complete inference from eight cells.
