# M5 development fixtures and targeting baselines

This is a development contract, not a held-out protocol freeze or an experiment
report. The generator runs no physics. Its histories, retained observations,
known expectations and outcomes are explicitly synthetic fixtures. They do not
establish physically acquired history, embodied transfer, or R2 completion.
The live M4 development profile still starts M unknown.

## Generation and independent truth

`make_case(seed, regime, split, *, kind='change')` returns separate public fixture
and private evaluator truth. Seeds are unsigned 32-bit integers. Regimes are
`local_cue` and `paired_cue`; splits are only `development-history` and
`development-test`. A held-out split is rejected until separately reviewed and
frozen. Fixed geometry follows the M4 cylinder world; this slice counterbalances
identifiers and associations, not arbitrary layouts.

The first three seed bits independently permute relation-to-physical-side,
fact lexical order, and subject lexical order. Eight consecutive seeds cover
all combinations. Every entity/evidence ID uses its split and seed namespace.
Current public M/event remain identical between regimes for a shared seed.
Own, swapped and current-case entity/evidence IDs must be disjoint.

Before geometry parks both gates. For `change`, the hidden mechanism closes the
gate on the side assigned the regime's relation. For `null`, the observed cue
changes while geometry stays unchanged. For `no-event`, geometry and cue state
stay unchanged and the trigger is absent. Every condition returns no targets
without invoking a selector when there is no trigger.

The evaluator retains both circle arrays and recomputes passage occupancy using
the independent local horizontal-crossing clearance calculation. Gold comprises
previously observed, pre-event verified expectations made stale by actual
before/after occupancy changes. Unknown facts supply no gold target. Gold never
comes from `fit`, `select`, U, or an inferred relation prediction.

The public targeting fixture contains only M, its retained synthetic before
observations, and the observed trigger. Future passage observations, geometry,
regime and gold remain private. Known M is constructed through `seed_m` from
retained synthetic samples; it is never presented as physically acquired evidence.
Strict source/protocol hashes and 64 KiB public/private case caps reject
incompatible or oversized fixtures. Validation binds seed/case ID, declared
regime/kind, physical frames, and public ID/relation counterbalancing to the
deterministic generator mechanism. Historical E keeps its existing 1024-episode
and 4 MiB bounds.

## Historical fitting and nine conditions

`make_history(seed, regime, *, episodes=4, unobserved_relation=None)` uses a fixed
two-side before/after synthetic observation schedule, independent of U. Episodes
are ordered; each contains actual published observation values. The optional
missing channel emits `unobserved`, never an unchanged/negative label.
`memory.fit(E)` receives E alone, uses the fixed M4 support thresholds, and can
abstain. No test bank/event, future trajectory, regime label or branch ID enters
fitting. Full source E remains in the comparison audit bundle.

`compare_conditions(fixture, own_E, swapped_E, truth, *, limit=1)` is an evaluator
wrapper. All conditions share M/event and the same target cap (default one,
validation ceiling eight). It runs these declared selectors:

| Condition | Guidance/access |
|---|---|
| own | fitted own U |
| swapped | fitted disjoint other-regime U |
| sham | exact copied own U; pure selection identity only |
| no-U | empty U; no targeting guidance |
| hand-authored | fixed `local_cue` rule; neither learned nor privileged |
| history-independent | canonical first fact, independent of cue/relation |
| traversal | associations mentioning the observed cue, canonical order |
| retrieval | full own E at runtime; latest complete matching-trigger episode |
| oracle | capped independent evaluator gold; explicitly privileged |

Retrieval abstains when its latest complete matching episode has other than
exactly one changed relation. Unobserved/conflicted checks are incomplete and
cannot provide negative evidence. Only artifact conditions are eligible for a
later U-only comparison; the other baselines change the method/information.
The fixture sham does not execute or qualify an atomic engine transaction.
Several baseline selections may coincide; nine labels do not guarantee nine
distinct mechanisms or independent samples.

## Readouts and limits

Record exact-set correctness, false/missed target counts, abstention and correct
abstention. Precision is undefined without selections; recall is undefined for
empty gold. Null abstention is correct. Report each paired case/history outcome;
frames are not sampling units. No mean, confidence interval or significance
claim is manufactured by this fixture helper.

Record canonical U payload bytes, full envelope bytes, retained E bytes, and
runtime input bytes separately. Full-envelope runtime input bytes describe
validation access; behavior access/bytes replace U with its payload and exclude
provenance. No-event cases have zero selector behavior bytes because selectors
are bypassed. Retrieval has additional runtime history
access; oracle has privileged gold. These are not equal-memory or equal-information
competitors. Runtime and consolidation cost remain unmeasured here.

No held-out seeds, sample size, acceptance effect threshold, numerical tolerances,
paired inference method, or embodied acquisition protocol is frozen by this file.
Those require a later explicit M5 review before held-out/closed-loop execution.
