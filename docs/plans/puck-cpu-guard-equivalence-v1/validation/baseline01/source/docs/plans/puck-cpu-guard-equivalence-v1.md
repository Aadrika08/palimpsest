# Authored guard union equivalence check

The product exit is one real recorded, replayed and exported public CPU episode.
Actual 09 failed and remains consumed. This source-only check decides whether a
fresh per-key accumulator can reduce temporary unions without changing current
dispatch and refusal behavior. It does not run installed vendors or actual 10.

Use base `31d980be15921b206eb77d2455931cc44c06270e`, bootstrap SHA256
`f137429398dc30270e67ef198c508231f9e2cf02d3aeedb98663630cafa51451`.
Production source remains unchanged throughout this experiment. One experimental
copy is permitted; a counterexample rejects it without a performance run.

## Literal existing evaluation

For each current `sys.modules` key, call `name.split('.')`, select element zero
and test stdlib membership. Only a non-stdlib key evaluates the whitelist:

1. Build the two-name literal and binary-union it with local aliases.
2. Evaluate `_loaded.keys()` and binary-union that result with the prior result.
3. Read `_loading` and binary-union that result with the prior result.
4. Test dependency truthiness. If true, evaluate dependency `loaded.keys()`, then
   `loading`, binary-union those two results and binary-union `exported`; otherwise
   create an empty set.
5. Binary-union that dependency result with the source result; test the original
   name against it. A refusal or any operator exception enters the existing
   first-failure, close and permanent-poison path.

Each key builds a fresh whitelist after its own split callback. Operand evaluation,
operator dispatch, collision/hash/equality callbacks and eager work are behavior;
matching final set contents alone does not prove equivalence. Existing direct
membership and hoisting counterexamples remain required.

## One candidate and the rejection gate

The candidate keeps per-key construction and operand order but replaces merges
into fresh temporary set results with in-place union. The new real-worker test
uses a source allowance set subclass whose reflected union raises a sentinel.
The existing binary operation must observe that exception, retain it as first
failure, close all owned holders and stay poisoned after cleanup. In-place
dispatch may skip the reflected method; if so, reject the candidate.
