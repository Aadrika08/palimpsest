# M7-REC-COVER-1 v3: prospective first-cycle collection boundary

This gate collects correctly separated expert/executed labels on two fixed obstacle approaches. It does **not** train a model, replace assets, change the teacher, admit these sources through the production loader, or open held-out data. The [v2 diagnosis](../reports/m7-training-v2-diagnosis.md) observed 1,983 training rows with zero contact inputs and one velocity target; contact-bearing development stalls motivate this diagnostic but do not establish a causal training remedy. Partial observability, imitation compounding and model capacity remain alternatives.

Rejection never relocates a start.

Each owner has at most 120 intervals. A local `prefix_active=True` starts the forward prefix (requested `[0.7, 0]`, with Engine's float32 conversion), bounded by **at most 32 intervals**. The same actual teacher is queried exactly once **before every interval**, including the prefix. Before choosing this interval's action, the first independently sampled bad-contact query or tick 32 switches `prefix_active` false **permanently**; that query's actual expert output is executed immediately. A clear sensor never reactivates prefix driving. This decision uses the observable contact boolean, not the teacher phase/count or evaluator pose. No reset at handoff, forced phase, direct control write, pose feedback/correction, retry or threshold tuning is permitted. The trusted direct owner uses the existing `Engine.advance(action_override=...)` to avoid a second teacher query. It records `recovery_expert_action` separately from the existing actual `action`, the applied prefix flag, before/after counters/direction/contact latch, transitions and expert query latency. Gate admission independently reconstructs the persistent latch from each published raw contact sensor and tick, verifies its flag and actual prefix/expert action, and refuses disagreement. Engine's override latency excludes this external expert query; report them separately rather than claiming ordinary teacher latency.

After that cycle, the first **subsequent fully admitted recorded interval** with both cached sensor and stage-zero intended-contact samples clear ends collection. All ten pre-control caches and the end cache still pass the unchanged guard.
