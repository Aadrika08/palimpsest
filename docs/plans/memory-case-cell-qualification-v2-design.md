## Exact identity and admission V2

Use proposed schema `memory-condition-cell-qualification-admission-v2` and a separately named V2 profile/condition extension. These names are design reservations, not existing accepted schemas. A follow-on implementation plan must enumerate exact bounded keys/types, source descriptors and serialization before adoption. Unknown fields, bool-as-int aliases, nonfinite numbers, ambiguous paths, aliases, duplicate roles and self-authentication must reject.

The fixed candidate remains `('development', 0, 0, 'change')`; these identities are deterministic unchanged-generator outputs, not a new case selection. The inspected generator yields seed **536870912** and case ID **`memory-family-v3-0279abe602574cd4166b0a86-change`** (family ID uses the first 24 hex characters of canonical SHA256 of `["development",0,0]`). Source-only `printf '%s' '["development",0,0]' | sha256sum` reproduced `0279abe602574cd4166b0a86bade1d4fd13b5f47aee5919fb4abac51fd40b949`, matching `memory.canonical_bytes` and the generator's ID construction. The complete canonical case and its `case_sha256`, graph/profile/acquisition hashes must be independently reproduced and frozen before runtime; the ID/seed alone are insufficient. No actual case payload, acquired SNP or model asset was opened here.

The new receipt must bind all of these identities together:

- The exact case/tuple/seed, generator and protocol versions, full source closure and all behavior/upstream source descriptors. No seed range or family-wide grant.
- The single accepted source owner/run UUID, source registration/commit/raw-audit descriptors, owner-source identity, source raw inventory, acquired boundary `b` and sole real `.pending/<case>/source/snapshots/initial.snp` descriptor (path/size/SHA), typed snapshot/application identity, event-prefix commitment and acquired hidden-state digest. No raw-local, post-repeat or replacement SNP.
- One prospectively reserved `own` owner/run UUID and job, frozen condition resources/history/U descriptors, common source reference, exact output/control namespaces and independently observed terminal controls. After closure, bind its actual report/manifest/events/raw inventory/raw-audit bytes and terminal-prefix discriminator. Source and condition must be from this one lineage.
- Exact unchanged full-FLYNN checkpoint, graph edge and seven mapping descriptors; model manifest/upstream identity; exact application and policy provenance including seed 536870912; immutable controller-tensor hashes. Never change live provenance/seed after load to fit a receipt.
- Executable venv entry and separately resolved ELF identity, clean installation/source-prefix closure, exact dependency/native/runtime roster and Python/NumPy/Torch versions/profile; CPU float32/eval/one numerical thread, gradients disabled, no CUDA. The current consumer requires Python 3.11.15, NumPy 2.2.5 and Torch 2.9.0; any prospective change needs its own review/qualification.
- Exact V2 compact profile/reader/consumer/admission hashes, native freeze and qualification freeze, external terminal and independently accepted outcome-audit descriptors, accounting totals and scoped claims. The trust-anchor source remains outside the receipt's authenticated source closure to avoid a circular pin.

Before observations, freeze the owner identity, immutable inputs, commands/environment, outputs, all bounds, qualification comparisons/negatives and the deterministic rules that close the inventory. Future raw bytes cannot have pre-observation hashes: their **actual** descriptors are appended only by the admitted close/audit path to that same reserved attempt. Reject a changed run or substituted inventory; never synthesize a successful receipt or treat later descriptors as a fresh allocation.

Admission V2 must refuse an unaccepted exact receipt before model imports/protected reads/output writes. A metadata-valid receipt grants nothing. Numerical qualification execution uses its separately reviewed freeze and held inputs; only **after** independently accepted actual outcome may a separate reviewed source change add the exact receipt `(path,size,SHA)` pin. Public sealing cannot self-issue that acceptance. Empty V1 pins remain empty; V2 has no environment/config/caller override or broad-seed trust switch.

Scope is also typed by actual evidence: a positive own prefix permits only `exact-source-and-observed-own-prefix-encoded-cell-only`; zero own permits only `source-encoded-cell-only-plus-own-terminal-integrity`. The zero variant grants **no own numerical/model qualification**. Its terminal evidence can receive 900 without that grant. A terminal-specific public seal route must enforce this distinction rather than pretending a vacuous condition replay satisfies an unchanged full-model gate. Neither variant qualifies unobserved continuation rows, other cases or the general study terminal domain.

## Numeric-complete retention before the own owner

Adopt and verify the V2 preservation domain before actual own collection. Retain every existing admitted numeric field plus the omitted channels below for **every actual source and continuation row**, including partial chunks. Copy dtype/shape/bytes exactly; retain original event/manifest bytes, old row/image commitments, selected pixels, source SNP and provenance. No conversion fallback to V1 after seeing an outcome.

| Additional retained field | Exact per-row wire dtype/shape | Increment |
| --- | --- | ---: |
| `latency` | `<f8`, scalar | 8 bytes |
| `step_latency` | `<f8`, scalar | 8 bytes |
| `population_stats` | `<f8`, `(3,4)` | 96 bytes |

Full-FLYNN population row order is `visual_left, visual_right, descending`; columns are `count, mean, min, max`. Engine writes float64 `.reshape(-1,4)` after a successful motor step (`engine.py:984–996`); `_population_stats:1136–1156` emits those three rows, including count-zero rows. Other controllers/overrides can produce `(0,4)` and the old validator permits variable `(N,4)`. Therefore `(3,4)` is an explicit new full-FLYNN eligibility check, **not an observed actual shape or a universal old guarantee**. Verify every acquired/own raw row and bind name/column order to source/manifest. Wrong shape/order/endian, missing/duplicate member, NaN/Inf or changed value is retained refusal, never zero-fill or inferred population.

Increment is 112 bytes per tick; new dense row total 19,646 bytes, with 19 members per chunk instead of 16. Legacy scientific trace equality still excludes only the two timing fields; timing retention does not make noisy latency part of own/sham/no-event scientific equality. Population values remain part of original row commitments. Most full image arrays remain omitted: this profile preserves admitted numeric channels, selected images and commitments, not all pixels/raw NPZ bytes, perception or physics replay.

The [preservation contract](../reports/memory-compact-preservation-2026-11-05/compact-preservation-contract.md#8-prospective-v2-option-retain-every-numerical-recording-channel) gives conditional maxima 33,536,672 source bytes within 32 MiB (17,760 bytes slack) and 25,545,720 condition bytes within 25 MiB (668,680 slack), **only if aggregate container/control overhead fits 1 MiB**. Prove actual canonical metadata, all 19 NPY/ZIP members per chunk, indexes/audit tick arrays, copied manifests/events/support/controls and atomic peaks before freeze. The existing 1 MiB legacy-manifest cap alone does not prove that combined bound. No compression/deletion credit, truncation or silent cap increase. Re-encode/compare the same retained Task 2 source raw under the adopted V2 public path if required; no new source owner is granted.

## Natural terminal prefixes, including zero/one/two rows

Preserve the registered rule in `memory-confirmatory-v3-design.md:137–140`: independently audited natural non-goal costs 900; goal costs actual continuation ticks. Acquisition/owner/audit/custody/runtime failures are unscored and stop. A legitimate pre-control `CueUnavailable` after acquired restore may have 0, 1 or 2 completed motor rows; the current later-domain restriction is not an unreachability proof. Do not pad, discard, replace, retry, choose another case or reclassify a natural failure as operational to fit a decoder.

Use an explicit V2 tagged `natural-terminal-prefix` variant. It covers a normally closed continuation from the authenticated acquired fork with exact restore/configure/arm, reached-world evidence and independently reproduced allowed terminal cause. Normal completed/postdecision cases retain all existing obligations; malformed normal evidence cannot fall through to this variant. The owner/controller behavior and `CueUnavailable` handling remain unchanged.

For zero completed intervals at boundary `b`, require:

- `row_count=chunk_count=0`, an exactly empty chunk index/directory, no motor chunk, `boundary_tick=terminal_sensor_tick=b`, `first_motor_tick=last_motor_tick=null`; no continuation policy call, native motor step or writer tick. Source acquisition remains nonempty.
- Empty audit tick array shape `(0,)`, dtype `<i8`, and paired camera arrays shape `(0,128,128,3)`, dtype `|u1`, with empty motor-frame schedule. No fabricated continuation observation; a separately needed source-boundary image has an explicit source role.
- Exact nonempty actual events/report/inventory/controls, including one ordered terminal `memory_sensed`/`runtime_failure` pair, the allowed target/message, post-exception cursor semantics and no subsequent sensed/policy/selector/physics/write progress. Reconstruct the terminal packet from authenticated source final `next_pose`/SNP/world geometry and replay pure memory state until that exact exception. A named exception or score alone is insufficient.
- Empty motor trace SHA256 and empty binary row/camera sequence hashes under unchanged formulas. Derive `goal=false`, `continuation_ticks=0`, `path_length=0`, `capped_ticks=900`, paired source invariant and exact terminal reason. No zero-tick goal.
- A replay result tagged `replay_scope=no-neural-call-terminal-prefix`, `rows_checked=0`, `model_inference_calls=0`. Record per-row numerical equality as not applicable, not a measured positive replay. Initial/final hidden identity is source-anchored unchanged state, not a newly observed rollout endpoint.

For positive prefixes use exactly the real rows/ticks and final post-step pose; replay every encoded row. Distinguish event-unreached, event-reached/decision-unreached and decision-reached outcomes. Validate only obligations whose boundaries were reached, **all** of those obligations, and no fabricated future gate/trigger/commitment. Retain the future frozen schedule as unexecuted. Full reached decision/gold requirements remain mandatory when reached. Existing V3 `_read_run`, V4 `_audit_rows`, `_condition_terminal`, compact schedule/chunk/frame readers and pair projection cannot handle this domain unchanged; the follow-on plan must version these paths consistently through raw audit, conversion, replay result, pair seal and retained endpoint reader.

The prior-own oracle donor rule is unchanged (`memory_family_oracle_admission_v4._prior_own:496–575`, `_condition_mapping:578–620`). If this real own prefix never reaches the required event/decision/gate occupancy, its natural 900 is valid when independently proved, but the oracle prerequisite is missing. Keep oracle unattempted and the case/study incomplete. No privileged future-world gold, fallback donor, rescue owner, extra event-reference run or complete inference from eight cells. Empty trace equality alone never proves no-event equality: later require actual zero selector invocations and equal outcome/count/path/invariant; own/sham equality remains mandatory.

## Predeclared discriminating controls and acceptance

Controls operate on private in-memory/candidate copies, never retained raw/SNP/assets. Freeze their exact implementation and expected rejection category before observations. Do not adapt a perturbation to an observed success. A nondiscriminating control fails qualification; a timeout/import/custody error does not count as the intended numerical rejection.

| Control fixed before own observations | Required discrimination |
| --- | --- |
| At source tick 0, add float32 `100` to every encoded component, preserving shape/dtype; separately add float32 `100` to both recorded raw-output components at tick 0 | Actual consumer rejects output/action or source endpoint mismatch. Source acquisition guarantees a nonempty control substrate; zero own is no excuse to omit these. |
| Add float32 `100` to a copied acquired hidden endpoint, preserving structure; replay the unmodified source | Source endpoint comparison rejects. For a positive own prefix, also replay with the changed initial hidden and require output/action mismatch; for zero own this latter numerical comparison is explicitly inapplicable. No new owner needed. |
| Change the same registered readout parameter copy used by qualification (`cell.readout_head.0.bias +=100`) before live immutable-tensor admission | Tensor identity rejects before replay; restore and independently rehash the original tensors and caller state afterward. |
| Wrong seed/case/SNP/prefix, model/runtime/provenance/consumer descriptor, untrusted pin, or source/condition swap | Admission rejects at its relevant identity gate, before ungranted reads/imports/writes. A digest-only mutation is an integrity control, not a numerical discrimination claim. |
| Changed latency bit or population bit/count/order; wrong shape/endian/nonfinite; missing/duplicate numeric member; altered original row/event/frame commitment; one byte over combined overhead/total bound | Independent raw-versus-V2 preservation rejects the exact mismatch/domain/cap; no downgrade or successful-subset claim. |
| Empty acquisition/zero goal, missing chunk disguised as zero, fake motor frame, wrong terminal geometry/message, duplicate terminal pair, progress after exception, or unreached gold claimed reached | Terminal-prefix auditor rejects; legitimate 0/1/2-row natural 900 evidence remains representable. Missing oracle donor stays incomplete. |
| Held-input edit/restore, alias/namespace change, non-drained owner, unknown CPU, late terminal/close/publication or final recheck failure | Reject and retain failure even after intermediate success; no accepted export/pin/seal. |

Before actual qualification, authored fixtures must cover ordinary positive/reached paths, 0/1/2-row natural terminals and each negative across raw/V2 compact/pair/replay/retained reductions; legacy schema/bytes stay unchanged. These are required future tests, **none run here**. The follow-on freeze must derive worst-case cell-call/CPU limits for positives, all predeclared negatives, later seal/read replay and all parents/drains/audits without double-counting subtree CPU. No historical 737/1,470 count or owner wall ceiling is a measured new bound.

Actual independent acceptance requires complete immutable input/output/control inventory, exact external timely exit/reap/drain, no failure marker, every frozen positive/negative result, actual call counts and all final rechecks, scoped preservation/omission report and complete accounting. Keep technical qualification, independently proved natural 900 and missing study prerequisites separate. No status supplied by a worker/sealer constitutes independent acceptance.
